# Rosita’s little surprises

Una pequeña app de pistas y regalos protegidos con contraseña creada para Rosita.

El progreso avanza automáticamente según la fecha en Lima, sin depender del almacenamiento del navegador.

## Desarrollo local

No necesita instalación ni proceso de compilación. Abre `index.html` directamente o sirve la carpeta con cualquier servidor estático.

## GitHub Pages

El workflow incluido publica la rama `main` automáticamente en GitHub Pages.
